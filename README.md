# iyf-s12-week-05-chukwuma-n

## Project Description

This is my IYF Season 12, Week 5 DOM Manipulation project. It includes an interactive To-Do List application, DOM practice exercises, and five daily coding challenges built with HTML, CSS, and JavaScript.

## Features

### To-Do List
- Add tasks using the Add Task button or Enter key.
- Reject empty or whitespace-only tasks.
- Mark tasks as completed.
- Delete individual tasks.
- Filter tasks by All, Active, and Completed.
- Display the number of remaining tasks.
- Clear all completed tasks.
- Edit tasks by double-clicking their text.
- Press Enter to save an edit or Escape to cancel.

### DOM Practice
- Select and traverse DOM elements.
- Change text, attributes, and CSS classes.
- Create, insert, clone, and remove elements.
- Handle click, keyboard, and form events.
- Practise event bubbling and event delegation.
- Validate form input.

### Daily Challenges
1. Change heading colours randomly.
2. Create and insert a new element.
3. Remove images from a page.
4. Copy text between elements.
5. Toggle between light mode and dark mode.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Visual Studio Code
- Git and GitHub

## How to Run the Project

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using Live Server, or open it directly in your browser.
4. Open `dom-practice.html` to explore the DOM exercises.
5. Open the HTML files inside `daily-challenges/` to test the daily challenges.
